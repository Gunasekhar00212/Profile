## 💫 About Me

🌍 **Data is my country, and I’m always exploring its different states** — Artificial Intelligence, Machine Learning, Deep Learning, Natural Language Processing, Generative AI, and beyond.

I learn by focusing on four things:

- Understanding the fundamentals
- Connecting concepts to real-world applications
- Building practical solutions
- Exploring, improving, and moving forward

> **Learn → Understand → Build → Explore → Move**

I believe technology is not about collecting tools or following trends. It is about understanding how things work and turning that knowledge into useful, working systems.

### 🧱 Foundations

Alongside AI and data, I am strengthening my foundations in:

- Data Structures and Algorithms
- Object-Oriented Programming
- Database Management Systems
- Operating Systems
- Computer Networks
- Core Computer Science concepts

### 🎯 My Goal

My goal is to understand problems deeply, work with data effectively, and build intelligent systems that create real-world value.
